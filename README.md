# Machine Learning Projects — Coding Camp x DBS Foundation

## About This Repository

This repository contains the final projects I completed during the **Machine Learning learning path of Coding Camp powered by DBS Foundation**.

Throughout the program, I worked on projects covering Data Analysis, Machine Learning, and Deep Learning using Python. Each project allowed me to apply what I learned in the courses and gain hands-on experience working on different data-related problems.

One of the valuable parts of this program was the project review process. Each final assignment was reviewed by professionals in the relevant fields and evaluated against predefined criteria. Projects that did not meet the requirements received feedback and guidance for improvement before being resubmitted. This process helped me learn from feedback, improve my implementations, and better understand the standards expected in practical projects.

## Projects

### Data Analysis

**1. Sentiment Analysis — Block Blast Reviews**
- Collected user reviews through web scraping and prepared the data for analysis.
- Performed text preprocessing and sentiment classification.
- Achieved **93.58% accuracy**.

**2. ETL Pipeline**
- Built a modular pipeline to collect, transform, and load data.
- Implemented web scraping, data transformation, data loading, and unit testing.
- Achieved **93% test coverage**.

### Machine Learning

**3. Loan Approval Prediction**
- Built predictive models using Logistic Regression and Random Forest.
- Evaluated model performance using accuracy and ROC-AUC.
- Achieved **96.3% accuracy** and a **0.9948 ROC-AUC score**.

**4. Fraud Detection — Bank Transactions**
- Explored transaction patterns using K-Means clustering.
- Applied classification models to identify potentially fraudulent transactions.
- Achieved at least **92% accuracy and F1-score**.

**5. Book Recommendation System**
- Developed a book recommendation system using Content-Based Filtering and Collaborative Filtering.
- Applied Singular Value Decomposition (SVD) for collaborative recommendations.

### Deep Learning

**6. Image Classification — Butterflies and Moths**
- Built image classification models using CNN and MobileNetV2.
- Worked with a dataset covering 100 butterfly and moth species.
- Achieved **97% test accuracy**.

**7. Plant Disease Classification**
- Developed an image classification model using TensorFlow and Keras.
- Classified plant leaf images into 16 disease and healthy-leaf classes.
- Prepared the model for deployment using TensorFlow Lite (TFLite) and TensorFlow.js.

## Tools and Technologies

- **Programming:** Python

- **Machine Learning:** Scikit-learn, Logistic Regression, Random Forest, K-Means, Recommendation Systems
- **Deep Learning:** TensorFlow, Keras, CNN, MobileNetV2

- **Deployment:** Streamlit, TensorFlow Lite, TensorFlow.js
